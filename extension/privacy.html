X 粉丝数隐私政策

更新日期：2026-10-10 · 发布者：vikyhuhu。本扩展与 X / Twitter 无官方关联。

用途与数据

仅在 X / Twitter 的 HTTPS 页面显示账号信息与粉丝趋势。读取页面自身已加载的公开用户资料：用户 ID、昵称、账号名、粉丝数、关注数、总发帖数、含图片/视频的帖数、注册时间、认证、专业账号类别及个人网站；读取当前登录账号的关注关系，并从账号切换按钮读取账号名以清空关系缓存。以上详情只保留在页面内存，刷新后重建。

可选本机记录

新安装默认开启粉丝趋势记录及全部详情显示项，可在工具栏随时关闭；升级保留已经保存的设置。记录开启时，扩展在 chrome.storage.local 保存已加载账号的用户 ID、观察时间与粉丝数。记录保留30天，最多1,000个账号，存储预算8 MiB；超限时移除较早记录。开关和显示偏好持续保存在本机。升级时移除旧版保存的资料和帖子样本，保留尚未过期的粉丝快照。

网络与分享

扩展不向开发者或第三方上传、出售、共享数据；无分析、广告、遥测或远程执行代码。只解析允许的用户／时间线读取响应（GET 或 POST），不主动查询账号，不读取请求头、Cookie、令牌、密码、私信、请求正文或完整浏览 URL 历史；不提取或保存帖子正文。打开个人网站、GitHub 或隐私政策链接是你的主动操作，目标网站按其自身政策处理请求。X 本身的数据处理受 X 的政策约束。

你的控制

工具栏设置可开启或关闭记录、选择详情字段，或确认清除全部趋势记录。关闭记录后停止新记录及趋势展示，但已有快照保留至到期或清除（保留期在处理本地记录时执行清理）；再次开启可恢复未过期的快照。卸载扩展会移除扩展本机存储。禁用扩展可停止运行。

有限使用与联系

数据仅用于本政策所述的账号信息显示与本机粉丝趋势功能，遵守 Chrome Web Store 用户数据政策及 Limited Use 要求，不用于广告、转售、信用或贷款判断；开发者无法访问本机数据。数据不是账号真实性或质量的证明。

联系与支持：GitHub Issues。请勿提交凭证或私人资料。公开隐私政策。
