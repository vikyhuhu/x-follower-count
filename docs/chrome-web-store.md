## 商店文案

名称：**X 粉丝数**

简短说明：在 X 名字旁显示粉丝数、关系与账号年龄；统一详情卡展示账号数据和近七天趋势。记录仅保存在本机。

详细说明（以下内容可填写）：

> 在刷 X 时直接查看页面已加载的账号信息。
>
> 信息流在账号和发布时间后显示粉丝数量、关注关系及账号年龄；用户列表和侧边推荐将标签放在 @账号下方，空间不足时换行。粉丝数按量级分色；注册未满90天显示「新号」。悬停或点击任意标签，查看精确粉丝数、关注数、粉关比、总发帖数及注册时间。总发帖数不等于全历史原创数，标签不评价账号质量。
>
> 新安装默认开启全部详情显示项和近七天粉丝柱状图：仅在本机保存已加载账号的用户 ID、观察时间与粉丝数。记录保留30天、最多1,000个账号；不会回溯未观察到的历史。可以在工具栏分别关闭详情项、关闭记录及趋势展示，或清除全部快照。升级保留已经保存的设置。认证状态、含图片/视频的帖数、专业账号类别及个人网站仅在页面提供数据时显示。账号详情和关注关系仅在当前页面内存中处理。
>
> 扩展读取 X 页面自身允许的用户／时间线读取响应（GET 或 POST），不额外查询账号，不提取或保存帖子正文，不解析私信及认证接口，不读取请求头、Cookie、密码或令牌，不上传数据，无广告或分析。仅在 X / Twitter 的 HTTPS 页面运行。
>
> 支持亮暗主题和键盘操作。需浏览器中已有的 X 登录状态来加载相应页面，扩展本身不要求登录授权或 API Key。X 改版可能影响显示，缺失字段不猜测。安装及更新后请刷新 X 页面。
>
> 本产品与 X / Twitter 无官方关联。数据使用说明：https://github.com/vikyhuhu/x-follower-count/blob/main/PRIVACY.md

默认语言：简体中文。类别可选与浏览账号信息相符的生产力类别，以实际后台选项为准。

首页：[源代码仓库](https://github.com/vikyhuhu/x-follower-count)。支持：[GitHub Issues](https://github.com/vikyhuhu/x-follower-count/issues)。隐私政策填写链接：[PRIVACY.md](https://github.com/vikyhuhu/x-follower-count/blob/main/PRIVACY.md)。

## 隐私与权限后台字段

**单一用途**：帮助用户在 X 页面查看已加载的公开账号信息及可选的本机粉丝数量观察趋势。

**storage 理由**：保存显示偏好；新安装默认开启记录，可随时关闭；记录开启时保存用户 ID、观察时间及粉丝数，供近七天本机柱状图使用。没有云同步。

**站点访问理由**：静态 content_scripts 仅匹配 HTTPS X / Twitter 四个域名，在页面开始加载时读取已发生的允许的读取响应（GET 或 POST）并插入账号标签。没有 `<all_urls>`、`tabs`、`cookies`、`webRequest`、`unlimitedStorage` 或额外 host_permissions。

**远程代码**：选择「不使用远程代码」。全部 JS / CSS 随安装包提供，API 返回的 JSON 仅作为数据处理，不执行服务端代码。

**数据类型**：应如实申报处理的数据，不能因为没有上传就填写「不处理任何用户数据」。按本版本实现，填写：

| 类型 | 本版本处理范围 |
| --- | --- |
| 个人身份信息 | 公开昵称、账号名、用户 ID；账号切换按钮的当前账号名只用于页面缓存失效 |
| 网站内容 | 已加载的公开账号字段及当前账号对应的关注关系，页面内存处理 |
| 网络浏览记录／活动 | 仅 X 页面加载的账号观察历史；记录开启时本机保存 ID、观察时间与粉丝数，不保存完整 URL 历史或其他网站活动 |

不处理健康、金融／支付、身份验证凭证、私信或按键／鼠标行为追踪。产品为浮窗所需的正常指针、键盘事件不是行为分析。实际后台表单名称可能变化，按上述范围一致填写。

有限使用声明应与代码和 [隐私政策](../PRIVACY.md) 一致：不出售／共享数据、不用于所述单一用途之外的目的、不用于信用或贷款判断。依据：[官方隐私字段](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)、[本地处理也须披露的 FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)、[隐私政策要求](https://developer.chrome.com/docs/webstore/program-policies/privacy)、[披露与同意要求](https://developer.chrome.com/docs/webstore/program-policies/disclosure-requirements)。

## 审核员验证步骤

1. 安装后登录 X，打开首页或用户列表并刷新。扩展没有单独登录流程，不提供测试账号或凭证。
2. 检查信息流账号名与时间后的标签按粉丝数、文字关注关系、账号年龄排序；用户列表及侧边推荐的标签在 @账号下方，名称与账号各自保留一行。外部不显示粉关比。任意标签打开相同详情卡；姓名附近为关注关系标签，详情中的粉关比小于1显示一位小数，大于等于1取整；关注数为零显示0，缺失字段显示「—」。X 原生用户名悬浮和插件标签悬浮各自独立。
3. 新安装时全部设置默认开启，今日柱子直接显示观察到的完整粉丝数；缺失类别等字段不显示。升级已有设置时保留明确关闭的选项。
4. 关闭记录后停止新记录及趋势展示；清除全部记录有确认步骤，显示偏好保留。工具栏可访问离线隐私政策。
5. 商店审核时可能只有一天记录，真实七天趋势需逐日观察；截图中的七天历史为合成数据。
